# Ultimate To-Do-List

## About

UTDL is a simple and easy to use **To Do List Application** made in python

## Installation

You can either install via the [Releases](https://github.com/Vedomom/Ultimate-TDL/releases), or by cloning the repository and building it via [PyInstaller](https://pyinstaller.org/en/stable/installation.html)

## How To Use

1. Create a new list by pressing the **New** button
2. Enter a valid List Name
3. Open the list by clicking on its name
4. Start adding tasks with the input field
